Welcome to CyberBank Demo

This is a simple Fineract-based frontend demo to demonstrate onboarding, transfers, and inquiries.

Current Client Current Client: None

All Dashboards / History queries will use this clientId by default.

Workflow

  1. Create a client on the Quick Onboard page.
  2. Open Core Bank backend to Approve + Activate the client account (if not done automatically).
  3. Create a savings account for the client on the Open Account page.
  4. Perform transfers between accounts on the Transfer page.
  5. View data on the Dashboard and History pages.

Health Check

Verify connection to Backend and Fineract.
